# Digital Shuffle Platform

This area mirrors the platform-planning role of JUN's digital-platform directory, adapted for Shuffle Timeline.

## Scope

- Static public archive at `/STL/`
- Searchable timeline extraction
- Source artwork viewer
- Agent-readable `llms.txt`
- Future source-review workflows

## Out of scope

- Copying JUN data registries
- Private community databases
- Personal contact exports
