# Shuffle Timeline investigative method

The original image is treated as the canonical visual source. The transcription file is useful, but it is not authoritative by itself because it was produced automatically and contained known mistakes.

## Extraction rules

1. Preserve the artwork as source evidence.
2. Separate the left introductory text from historical timeline events. It speaks to the community and explains the project; it is not itself a community/historical element.
3. Promote only readable items into the public timeline.
4. Mark uncertain readings instead of rewriting them as fact.
5. Keep names, dates and scene terms close to the image unless a correction is visually clear.
6. Mention project provenance: [@shuffletimeline](https://instagram.com/shuffletimeline), Gaara and LuVa.
7. Credit site implementation separately: the site was developed by Mreaggle from the work started by Gaara and LuVa.

## Confidence labels

- `clear`: readable directly from the original image.
- `supported`: readable with minor normalization for grammar or line wrapping.
- `uncertain`: visible in the artwork but not fully legible.
- `needs review`: present as a visual/text element, but still requires community confirmation.

## Current extraction status

The public extraction preserves the artwork's major visual chapters while publishing each readable claim as its own dated record. A record carries its own source list and review state; chapter-level links are never propagated to unrelated records. Precise dates are used only when supported, while approximate dates and ranges remain visible where the evidence is broad. Dense micro-text inside screenshots, flyers and small embedded images remains flagged for review instead of being presented as verified wording.
