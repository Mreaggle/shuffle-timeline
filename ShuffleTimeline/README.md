# Shuffle Timeline

Canonical human-readable timeline workspace.

The generated public Markdown is `dist/STL/timeline.md`. Source content is maintained in:

- `src/content/timeline.js`
- `src/content/shuffle-timeline.json`

## Major eras

- Underground Era — 1985–1997
- Transition Era — 1998–2005
- YouTube & Facebook Era — 2006–2014
- Instagram & TikTok Era — 2015–2024
